# Agent notes

## Rules

- Use Bun for everything: `bun`, `bunx`, `bun add`. Never use npm, npx, yarn or pnpm.
- Never use Python to edit or generate files. Use Bash (sed, heredocs) or the Edit/Write tools.

## ui-sdk

Before using ui-sdk, follow the `ui-sdk` skill if it's installed, and read `node_modules/@ui-sdk/react/docs/llms.txt`.

To build a new component, also search `node_modules/@ui-sdk/react/docs/core.md` by heading, and read `node_modules/@ui-sdk/react/docs/rendering.md`.
